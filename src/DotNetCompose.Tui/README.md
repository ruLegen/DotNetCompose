# DotNetCompose.Tui

A terminal UI adapter with composable text, layouts, borders, buttons, input,
lists, and themes. `TuiApplication` owns the terminal composition and event loop.

Targets `net10.0` and requires an interactive terminal for the default driver.
Use the SDK selected by [global.json](../../global.json); no MAUI workload is
needed. Authoring projects reference the runtime, TUI adapter, and generator
analyzer.
