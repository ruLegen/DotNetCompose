# DotNetCompose.Maui

A Compose-style UI layer over native MAUI views. `MauiComposeView` hosts screens;
the adapter provides components, layout modifiers, themes, canvas drawing,
and typed navigation.

Targets `net10.0` and `net10.0-windows10.0.19041.0`. The runnable application
sample targets Windows x64 and requires the .NET 10 MAUI Windows workload and
Windows App SDK runtime. Authoring projects reference the adapter and source
generator analyzer.
