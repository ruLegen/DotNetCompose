# DotNetCompose

A Jetpack Compose–inspired experiment in building a declarative, reactive UI
for C#. Not a full port — rather an attempt to bring Compose-like
composability and state-driven rendering to the .NET ecosystem.

## Key Features

- **`[Composable]` + Incremental Roslyn Generator** — methods marked with `[Composable]` are transformed at compile time into composable functions with parameter change tracking, restartable groups, and recomposition. The class must be `partial`.
- **Declarative approach** — UI is described as a function of state; the library decides what and when to redraw.

## Default parameters

Use `[Default<Provider>] T value = default` when an omitted argument needs a
computed value. The provider implements `IDefaultValueProvider` and exposes an
accessible static parameterless `T Create()` method. `Create()` can be a regular
method or an inline composable method (the provider class must then be `partial`).

```csharp
public sealed partial class TitleProvider : IDefaultValueProvider
{
    [Composable(ComposableMode.Inline)]
    public static string Create() { return App.LocalTitle.Current(); }
}

public static partial class App
{
    public static readonly ProvidableCompositionLocal<string> LocalTitle =
        Composables.CompositionLocalOf(() => "Untitled");

    [Composable]
    public static void Header([Default<TitleProvider>] string title = default)
    {
        Console.WriteLine(title);
    }
}
```

## Example (one composable calling another)

```csharp
// ===== What the user writes =====
using DotNetCompose.Runtime;

public static partial class App
{
    [Composable]
    public static void Header(string title)       // ─┐
    {                                              //  ├── composable A
        Console.WriteLine(title);                  // ─┘
    }

    [Composable]
    public static void Page(string title,          // ─┐
                             string content)       //  │
    {                                              //  ├── composable B
        Header(title);                             //  │   calls A
        Console.WriteLine(content);                // ─┘
    }
}
```

```csharp
// ===== What the Source Generator produces =====
// <auto-generated/>
using DotNetCompose.Runtime;

namespace <default>
{
    public partial class App
    {
        public partial class Builders
        {
            [ComposeGenerated]
            public static void Header(
                string title,                                                       // ← original parameter
                DotNetCompose.Runtime.Composer.IComposerContext __ctx,               // ← injected: composition context
                DotNetCompose.Runtime.ComposableArgumentsState __changed = default,  // ← injected: per-param change flags
                DotNetCompose.Runtime.ComposableArgumentsDefaultState __defaultParamState = default) // ← injected: default value indicators
            {
                try
                {
                    // === start of Header(string title) ===
                    __ctx?.StartRestartableGroup(/* hash of "Header" */);

                    // track parameter 'title' — maps to: Header(string title)
                    byte __title_state = __changed[0];
                    if (__title_state == DotNetCompose.Runtime.ComposableArgumentsState.Uncertain)
                    {
                        __title_state = __ctx.Changed(title)
                            ? DotNetCompose.Runtime.ComposableArgumentsState.Different
                            : DotNetCompose.Runtime.ComposableArgumentsState.Same;
                    }

                    // skip body if nothing changed and the composer says we can skip
                    if ((__title_state == DotNetCompose.Runtime.ComposableArgumentsState.Same
                         || __title_state == DotNetCompose.Runtime.ComposableArgumentsState.Static)
                        && __ctx.Skipping)
                    {
                        __ctx.SkipToGroupEnd();
                    }
                    else
                    {
                        // original body of Header:
                        Console.WriteLine(title);
                    }
                }
                finally
                {
                    // === end of Header(string title) — register for later recomposition ===
                    DotNetCompose.Runtime.IComposeUpdateScope? scopeUpdater =
                        __ctx?.EndRestartableGroup(/* hash of "Header" */);
                    if (scopeUpdater != null)
                    {
                        byte[] __defaultStateValues = __defaultParamState.CloneValues();
                        scopeUpdater.UpdateScope(context =>
                        {
                            Header(title, context,
                                DotNetCompose.Runtime.ComposableArgumentsState.Force,
                                new DotNetCompose.Runtime.ComposableArgumentsDefaultState(__defaultStateValues));
                        });
                    }
                }
            }

            [ComposeGenerated]
            public static void Page(
                string title,                                                       // ← original parameter
                string content,                                                     // ← original parameter
                DotNetCompose.Runtime.Composer.IComposerContext __ctx,               // ← injected
                DotNetCompose.Runtime.ComposableArgumentsState __changed = default,  // ← injected
                DotNetCompose.Runtime.ComposableArgumentsDefaultState __defaultParamState = default) // ← injected
            {
                try
                {
                    // === start of Page(string title, string content) ===
                    __ctx?.StartRestartableGroup(/* hash of "Page" */);

                    // track parameter 'title' — maps to: Page(string title, ...)
                    byte __title_state = __changed[0];
                    if (__title_state == DotNetCompose.Runtime.ComposableArgumentsState.Uncertain)
                    {
                        __title_state = __ctx.Changed(title)
                            ? DotNetCompose.Runtime.ComposableArgumentsState.Different
                            : DotNetCompose.Runtime.ComposableArgumentsState.Same;
                    }

                    // track parameter 'content' — maps to: Page(..., string content)
                    byte __content_state = __changed[1];
                    if (__content_state == DotNetCompose.Runtime.ComposableArgumentsState.Uncertain)
                    {
                        __content_state = __ctx.Changed(content)
                            ? DotNetCompose.Runtime.ComposableArgumentsState.Different
                            : DotNetCompose.Runtime.ComposableArgumentsState.Same;
                    }

                    // skip body if all params unchanged and the composer allows skipping
                    if ((__title_state == DotNetCompose.Runtime.ComposableArgumentsState.Same
                         || __title_state == DotNetCompose.Runtime.ComposableArgumentsState.Static)
                        && (__content_state == DotNetCompose.Runtime.ComposableArgumentsState.Same
                            || __content_state == DotNetCompose.Runtime.ComposableArgumentsState.Static)
                        && __ctx.Skipping)
                    {
                        __ctx.SkipToGroupEnd();
                    }
                    else
                    {
                        // call to Header(title) — maps to: Header(title) inside Page
                        global::App.Builders.Header(
                            title,
                            __ctx,
                            new DotNetCompose.Runtime.ComposableArgumentsState(
                                stackalloc byte[] { __title_state }  // 1 byte = 1 param of Header
                            ),
                            default);

                        // original body of Page:
                        Console.WriteLine(content);
                    }
                }
                finally
                {
                    // === end of Page(...) — register for later recomposition ===
                    DotNetCompose.Runtime.IComposeUpdateScope? scopeUpdater =
                        __ctx?.EndRestartableGroup(/* hash of "Page" */);
                    if (scopeUpdater != null)
                    {
                        byte[] __defaultStateValues = __defaultParamState.CloneValues();
                        scopeUpdater.UpdateScope(context =>
                        {
                            Page(title, content, context,
                                DotNetCompose.Runtime.ComposableArgumentsState.Force,
                                new DotNetCompose.Runtime.ComposableArgumentsDefaultState(__defaultStateValues));
                        });
                    }
                }
            }

            static class __StoredLambda { }
        }
    }
}
```

## Argument state buffers and Hot Reload

The source generator tracks argument changes and omitted default arguments in
temporary buffers. Configure their storage in the consuming project's `.csproj`
or `Directory.Build.props`, including when using DotNetCompose from NuGet:

```xml
<PropertyGroup>
  <DotNetComposeUseStackAllocForArgumentStates>false</DotNetComposeUseStackAllocForArgumentStates>
</PropertyGroup>
```

When unset, the setting follows the consuming compilation's optimization level:
Debug avoids explicit `stackalloc`, while Release uses it. Explicit `true` always
uses `stackalloc`; explicit `false` always avoids it. Empty or invalid boolean
values use the automatic mode. The build configuration of the generator itself
does not affect this choice.

Without `stackalloc`, C# 12+ targets supporting inline arrays use collection
expressions passed directly to `Span<byte>` or `ReadOnlySpan<byte>`. This allows
the compiler to use local inline arrays without heap allocation. Older language
versions or targets use `byte[]` buffers instead. Empty buffers allocate nothing.

The setting covers argument change states, default masks, restart lambdas, and
argument states reported to diagnostics. `DotNetComposeGenerateDiagnostics`
independently controls whether diagnostics are generated.

Avoiding generated `stackalloc` removes the ENC0044 blocker for Hot Reload;
other standard C# Hot Reload restrictions still apply. User-written `stackalloc`
is unaffected.

### Diagnostic line numbers

Diagnostic source line numbers are disabled by default in both Debug and Release:

```xml
<PropertyGroup>
  <DotNetComposeGenerateDiagnosticsLineNumbers>false</DotNetComposeGenerateDiagnosticsLineNumbers>
</PropertyGroup>
```

Set this property to `true` to report the actual source line. Otherwise diagnostics
report `0`, meaning an unknown line; the file path and member name remain available.
Missing, empty, or invalid boolean values are treated as `false`. This property is
independent of `DotNetComposeGenerateDiagnostics` and does not enable diagnostics.
Debugger `#line` mappings remain enabled and retain their actual source coordinates.

> **Note — Hot Reload:** Generating diagnostic line numbers can break Hot Reload
> after inserting or deleting source lines. Changed line-number literals update
> otherwise unchanged generated methods containing lambdas. In the reproduced
> case, Roslyn fails while emitting the EnC delta with `ENC1002` and
> `ArgumentException: An item with the same key has already been added` in
> `DeltaMetadataWriter.GetDelta`. A similar failure is documented in
> [dotnet/roslyn#77224](https://github.com/dotnet/roslyn/issues/77224); a shared root
> cause has not been established. Keep `DotNetComposeGenerateDiagnosticsLineNumbers`
> set to `false` for Hot Reload. Debugger source mappings are preserved.
